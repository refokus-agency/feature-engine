## Steps

1. **Update `package.json`** — rename to `@refokus-agency/feature-engine`, add `./vite` export entry, add `acorn` + `vite` as deps, update description/keywords/repository
   **Done when:** `name` is `@refokus-agency/feature-engine` and `exports["./vite"]` exists

2. **Update `tsconfig.json`** — add `"lib": ["ES2022", "DOM", "DOM.Iterable"]` to compilerOptions
   **Done when:** `tsc --noEmit` passes with DOM types available

3. **Update `vite.config.ts`** — set test environment to `jsdom`, add `jsdom` devDep
   **Done when:** vitest config includes `environment: 'jsdom'`

4. **Update `.releaserc.json`** — add `@semantic-release/git` to plugins array
   **Done when:** plugins array includes `@semantic-release/git`

5. **Replace `src/` placeholders** — create stub `src/index.ts` and `src/vite/index.ts`, delete `src/example/`
   **Done when:** `tsc --noEmit` passes, no references to example/

6. **Verify `npm pack`** — run pack and inspect contents
   **Done when:** .tgz excludes tests and .map files, includes dist/

## Interfaces

- **FeatureMeta**: feature id to lazy import mapping (Record<string, () => Promise<FeatureDescriptor>>)
- **LoaderOptions**: timeout (number), logging (boolean)

## Function Design

- `src/index.ts`: re-exports defineFeature, loadFeatures, and all public types (stubs only)
- `src/vite/index.ts`: exports featureMetadataPlugin factory stub (Vite plugin)

## Acceptance Criteria (EARS)

- AC-1. The package shall be named `@refokus-agency/feature-engine` with correct exports for `.` (main entry) and `./vite` (plugin entry)
- AC-2. When `tsc` runs, it shall compile with strict mode, DOM types, and generate .d.ts declarations in `dist/`
- AC-3. When `npm pack` is run, the resulting .tgz shall include `dist/**/*`, `README.md`, and `LICENSE`, and shall exclude tests, source maps (.map), and src/
- AC-4. When the repo template already has a pack/publish workflow, it shall be adapted (not replaced) for the new package name
